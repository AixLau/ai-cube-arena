# 魔方智竞 · AI 多阶魔方能力评测平台

AI 模型三阶魔方评测工具：填写供应商的 API 地址与密钥，系统自动获取该供应商提供的模型；勾选模型、难度与推理强度后，各模型从**同一个打乱状态**并发复原魔方，实时对比并可回放。平台本身不提供模型。

## 快速开始

```bash
npm install            # 会通过 postinstall 自动应用 patches/ 中的 cubing.js 修复
cp .env.example .env   # 可选：配置 HTTPS、并发等
npm run dev            # 前端 http://localhost:5173 ，后端 http://localhost:8787
```

进入「竞技场」创建测试：在 01 添加服务商（协议 + API 地址 + API Key，自动获取模型列表），02 勾选参测模型，03 选择魔方阶数与打乱步数，04 设置各模型的推理参数，05 选择运行限制并确认摘要，点击「开始测试」后实时观看。历次结果在「测试报告」中查看、回放与导出。

生产部署：

```bash
npm run build
REQUIRE_HTTPS=true npm start   # Node 服务同时提供 API 与静态页面
```

测试：`npm test`（魔方引擎、地址拼接、SSRF 防护、脱敏、四种协议适配器、多模型并发评测）。

上线前门禁：`npm run verify:release`。真实供应商链路需要通过环境变量运行 `npm run smoke:provider`，详见 [RELEASE_NOTES.md](./RELEASE_NOTES.md)。

## 功能

- **官网首页**：品牌主视觉、three.js 实时渲染的 3D 魔方（悬浮、层转动、可拖拽）、环绕式示例模型卡片、平台优势与「接入模型 → 选择难度 → 查看示例 → 进入竞技场配置」四步引导；首页示例模型和模拟演示不会调用真实 API，阶数与打乱程度会带入竞技场。支持浅色 / 深色主题（记住选择，首帧无闪烁）。
- **多阶魔方**：2×2、3×3、4×4、5×5，统一使用 18 种外层转动；引擎按阶数生成转动置换，提示词按阶数说明朝向与编码。
- **模型配置（供应商）**：只需填写接口协议、API 地址、API Key；保存后自动调用供应商的模型列表接口获取可用模型，可随时刷新。名称、认证方式、最大并发请求数放在「高级」中，均有默认值。供应商不支持模型列表时，可在卡片上手动补充模型。支持测试连接（检查工具调用支持）、编辑、复制、删除。
- **多协议适配器**：OpenAI 兼容 Chat Completions（主力）、OpenAI Responses、Anthropic Messages、Google Gemini，各自独立实现工具调用格式；新增协议只需实现 `ProtocolAdapter`（`server/adapters/`）。
- **推理强度**：每个参赛模型可选 默认 / 低 / 中 / 高。Chat Completions 发送 `reasoning_effort`，Responses 发送 `reasoning.effort` 并请求简洁推理摘要，Anthropic 发送 `thinking.budget_tokens`，Gemini 发送 `thinkingConfig.thinkingBudget`；「默认」不发送强度参数。Responses 的加密推理项只在内存中回放，不写入评测记录；旧中转拒绝可选字段时自动回退。模型拒绝推理强度参数时自动去掉重试一次，并在卡片与对比表中标注「已回退默认」。
- **竞技场 · 创建测试**：服务商卡片、可搜索的模型选择、魔方阶数与打乱步数（预设 10 / 20 / 40 / 60 步，可自由填写 1～100）、逐模型推理参数（额外思考、推理强度、最大输出 Token）与运行限制预设（快速体验 / 标准评测 / 深度评测）；启动前展示模型、规则、调用上限、并发和费用口径，草稿自动保存在本浏览器。
- **竞技场 · 测试进行中**：计时器与全部暂停 / 停止、动画速度；每个模型默认突出状态、复原结果、步数、用时、API 调用和最新操作，Token、费用、QTM、延迟等放在技术详情；断线后保留 run 锁定，自动/手动重连、终止和最近更新时间均可见；测试信息与初始打乱状态（可复制）；底部「操作记录 / 模型输出 / 状态对比 / 关键指标 / 思维过程」并可导出日志。
- **同题评测**：服务端只打乱一次；每个模型独立的魔方状态、计步、计时、Token 统计与复原判定；真正并发运行，可配置单局并发与全局并发；单个模型暂停 / 继续 / 停止，以及终止全部。
- **实时可视化**：按参赛数量自动排列；超过 8 个模型时默认延迟非聚焦 3D，聚焦后再加载；3D 加载失败提供可见重试和结果降级。支持聚焦查看、单模型/全部暂停与带费用提示的停止确认。
- **统计与回放**：结束后生成横向对比表；保存初始状态、供应商与模型标识（不含密钥）、完整动作轨迹，支持历史搜索筛选分页、按真实时间轴同步回放、上一步/下一步、首个错误、轨迹类型过滤和导出 JSON；排行榜按供应商 + 模型 + 推理强度汇总并标注样本量。
- **自由练习**：18 种基本转动、面转 / 四分之一转计数与计时；复原成绩锁定，支持撤销、重做、保留成绩后重新打乱和继续非计时练习。

## 评测规则

- 工具 `rotate_cube({ moves: string[] })`，只允许 18 种记号；单次动作数由本局 `maxMovesPerCall` 限制，已确定的完整公式通常一次提交一段，只有依赖新状态时才拆分；含非法记号时整批拒绝、不执行，并返回结构化错误和最新 canonical state。
- 模型收不到打乱公式。每轮请求包含当前 canonical state（状态编码规范 `facelet-net-v1`：展开图、逐面格子、state hash、solved、动作计数）、最近 6 次调用事实和模型备注；编排器保留所有原始 assistant/tool 协议块，适配器只负责协议转换。下一步必须由最新工具结果驱动。
- 每局由统一运行配置限制 API 调用次数、运行时间、单次动作数、连续无工具轮数和连续无进展轮数；复原、预算耗尽或看门狗触发时结束（暂停时不计时）。
- 模型未调用工具时，下一次请求强制工具调用（供应商不支持则回退为 auto）；网络错误、超时、5xx 自动重试最多 2 次（计入调用次数），429 按 Retry-After 重试且不计入。

## Token 与费用口径

- 只使用供应商返回的真实用量，未返回显示「未知」，部分缺失以 * 标注。
- 推理 Token 作为输出 Token 的组成部分单独展示，不重复累加（Gemini 的 thoughts 会并入输出后再计费）。
- 费用只采用供应商在响应中返回的计费金额（如 `usage.cost`），单位以供应商为准；供应商未返回时显示「未知」，系统不按任何价格表估算。

## Base URL 规则

| 协议 | 填写示例 | 最终请求地址 |
| --- | --- | --- |
| Chat Completions | `https://relay.example.com/v1` | `…/v1/chat/completions` |
| Responses | `https://api.openai.com/v1` | `…/v1/responses` |
| Anthropic | `https://api.anthropic.com` 或 `…/v1` | `…/v1/messages` |
| Gemini | `https://generativelanguage.googleapis.com/v1beta` | `…/models/{模型}:generateContent` |

不写死官方域名，不自动追加或重复拼接 `/v1`；已经是完整端点时原样使用。表单会实时显示最终地址，测试连接 404 时会提示是否缺少版本路径。

## 安全

- 所有模型请求由后端代理发起；供应商配置与 API Key 保存在浏览器端，刷新模型、测试连接和启动评测时临时提交。服务端不维护供应商配置或密钥存储，评测结束后释放临时配置和密钥。生产环境应启用 HTTPS。
- 浏览器使用无持久有效期的会话 Cookie 保存随机会话标识，配置与密钥保存在当前同源的 `localStorage`，仅当会话标识匹配时读取。同一浏览器会话内，刷新、关闭/重开标签页、多标签页共享均保留配置；新会话首次访问时清除旧配置。Cookie 不包含供应商配置或 API Key。
- 配置按浏览器定义的会话生命周期失效，不保证在进程退出瞬间物理删除本地数据。启用“恢复上次会话”时，浏览器可能恢复会话 Cookie，配置也可能继续保留；这不是严格的浏览器进程重启检测。此规则在配置页面和表单中明确提示。
- 会话存储要求支持 Web Locks 的新版浏览器以及 HTTPS（本地开发可用 `localhost`），以保证多个标签页不会互相覆盖配置。Cookie 或存储被禁用时会明确报错，不会显示保存成功。
- 密钥不会出现在日志、错误信息、SSE 事件、评测记录与导出文件中；上游错误内容先脱敏（含供应商打码回显的尾号）。评测记录仅保留展示所需的供应商名称、主机、协议、模型等快照，不包含完整连接配置。
- 自定义地址 SSRF 防护：仅 HTTPS；拒绝内网、回环、链路本地、CGNAT、云元数据、保留与组播地址（含 IPv4 映射 IPv6）；**连接时**再次校验 DNS 解析结果（防 DNS 重绑定）；不跟随重定向；响应体大小上限。
- 不提供服务端环境变量预置供应商；每个服务商都必须由当前浏览器会话配置。
- `REQUIRE_HTTPS=true` 强制 HTTPS 并发送 HSTS。

## 技术架构

| 部分 | 技术 |
| --- | --- |
| 前端 | React 19 + TypeScript + Vite，react-router |
| 3D 魔方 | 评测与回放：cubing.js `TwistyPlayer`（2～5 阶，层旋转动画，拖拽视角），`patches/` 修复了切换显示选项后画面回退的问题；首页主视觉：three.js（圆角块体、物理材质、环境反射） |
| 状态引擎 | `shared/cube.ts`：独立实现的 N 阶贴纸模型（6×N×N），前后端共用 |
| 后端 | Node.js + Express（tsx 运行 TypeScript），SSE 推送评测事件，undici + 自定义 DNS 校验发起上游请求 |
| 存储 | 浏览器 `localStorage` + 会话 Cookie（供应商配置与密钥，按浏览器会话失效）、`data/runs/*.json`（评测记录） |

```
shared/   cube.ts 状态引擎 · types.ts 共享类型 · endpoint.ts 地址拼接
server/   index.ts 路由
          adapters/  各协议适配器与安全 HTTP 客户端
          arena/     run.ts 同题评测引擎 · prompt.ts 提示词与工具定义 · store.ts 记录存储
          providers/ store.ts 临时配置校验 · models.ts 获取模型 · test.ts 测试连接
          security/  url.ts SSRF 防护 · redact.ts 脱敏
src/      pages/ 首页、竞技场、模型配置、历史回放、排行榜、自由练习 · components/ 卡片、表单、魔方视图等
```
